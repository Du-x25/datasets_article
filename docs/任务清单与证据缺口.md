## 证据链现在是否闭合

**尚未闭合。** 闭环是：采集身份 → 原始文件与成图变换 → 独立检查点精度 → A/B 不确定性 → 局部质量与内容覆盖 → 版本冻结 → 公平训练/共同测试支持 → 逐地点结果与失败分析 → 可下载复现。现在缺的是中间的真实人工证据和后面的正式实验、发布验证。

| 缺口 | 重要性 | 补强方式 | 没有它的风险 |
|---|---|---|---|
| 独立几何精度 | 核心 | 六模态原图点，经冻结变换统一计算；同时报告缺失率和覆盖 | 自动特征自证，无法判断错位是不是生成误差 |
| 标注可靠性 | 核心 | 盲法 B 原始差异、困难分层、协商另存 | 残差可能主要来自标注噪声，却被误解成配准误差 |
| 巡检完整性 | 核心 | 全场景六模态巡检签收 + 当前区域复核 | 没标到的坏区被误当干净区 |
| 三池可比性 | 核心 | 等地点计数 + 去重面积/来源匹配 + 固定测试支持 | “筛选收益”其实来自训练量、地点构成或容易的测试区域 |
| 内容覆盖与缺类 | 重要 | 明确已标区域分母，缺类不填 0，混合独立报告 | 小块路面被当作整地点或整体数据代表 |
| 地点外推与不确定性 | 核心 | 五折、五种子、地点配对/等权、逐地点值 | 裁块数被当样本量，结果显得虚假稳定 |
| 与既有工作增量 | 核心 | 公开说明旧数据/图像重叠、新增波段/场景、协议与复用资产 | 数据新颖性与重复发表疑问无法答复 |
| 数据公开可用性 | 核心 | 许可、隐私、DOI、文件 hash、复算脚本与独立试跑 | 技术验证做完，读者仍不能真正复用 |
| 大规模额外标注/外部新地点 | 非默认必须 | 仅当主张需要、或覆盖/置信区间暴露不足时增加 | 盲目加工作量却不能补关键证据 |

## 如何把收益最大化

1. 每种人工动作先对应一个可检验的问题和图表，再决定是否要增加标注；没有用途的精细描边先不做。
2. 先试标并记时，用“每视野分钟数×剩余视野 + 区域巡检 + B 复核”估算工作量，不把 1400 点误解成 1400 次点击；全六模态目标约 8400 个坐标槽，B 另占一部分。
3. 采用“每地点闭环”：A 点完成→冻结抽样→B 独立复核；区域编辑完成→B 最终复核。不要最后才发现所有区域复核因版本更新过期。
4. 把点身份、原图 hash、版本、缺失和分歧记录完整，后续多个变体可复用同一份原始观察；像素值/坐标来源一变就重新核对。
5. 提前固定统计和展示规则；好结果、坏结果、缺失都报告。结果阴性也能告诉使用者在哪些条件下质量筛选无效。
6. 优先闭合核心证据，再决定补多少图。丰富的补充材料承载分地点全表，正文保留回答关键问题的图，避免数量淹没主结论。
