## 数值与口径

- 代码：陈启栋 `pix2pixhd-p-noshuffle`，29 个源文件与参照副本的 SHA-256 一致；`label_nc` 0、`loadSize` 256（训练时随机裁至 128）、批大小 4、Adam $2\times10^{-4}$、$\beta=(0.5,0.999)$，100 个 epoch 后学习率线性衰减。参照代码不设随机种子。
- 4:1 窗口：成画布上步长 128、整窗位于几何有效区域的 $1024\times1024$ 位置缩放至 256，剔除平坦窗口后共 3,552 个，划分 2,842/710。归档数据为 7 个场景的 3,715 个图块，划分 2,972/743。
- 1:1 窗口：每地点 400 个，共 3,886 个，划分 3,109/777。
- 指标对测试窗口逐一计算后取算术平均；差值的 95% 置信区间按场景整群 bootstrap（20,000 次重采样）。
- 公开实现的数据加载器把每轮参与训练的窗口数取为批大小的整数倍，文件列表末尾不足一个批的窗口不参与训练。全量数据每轮实际使用 2,840 个窗口（划分中 2,842 个），25%、50% 子集和场景划分 A 各少 2 个，1:1 窗口少 1 个；每个 epoch 的更新次数据此计算。
- 同配置对照：100 个 epoch 24.46±1.12 / 20.26±1.80 dB（差 4.19 dB），两套数据各 3 次独立训练，取值范围分别为 23.17–25.22 dB 和 18.18–21.33 dB；200 个 epoch 28.88±0.06 / 22.91±0.18 dB（差 5.97 dB），各 3 次训练，取值范围分别为 28.81–28.93 dB 和 22.76–23.10 dB。500 个 epoch 为 30.18 dB 对 23.25±0.59 dB，只作为预算敏感性报告。
- 逐场景：100 个 epoch 时本数据集十个场景为 21.71–27.82 dB（3 次训练的均值），训练间标准差最大 1.65 dB，任意两次训练的场景排序秩相关不低于 0.95。
- 窗口尺度：1:1 窗口 100 和 200 个 epoch 为 18.02 和 20.72 dB，比同预算的 4:1 窗口低 6.44 和 8.16 dB。
- 三模型对比沿用 2026-11-12 的记录（batch 4、200 epoch、种子 11）：DRUNet 36.438、TFD-GAN 29.054、pix2pix 25.106 dB。
- 输入波段消融（每种输入 1 次训练，100 个 epoch）：B3、B234、B345 比参照输入 B123 低 2.56–3.69 dB，十个场景上均低于参照；其余 11 种输入与参照相差不超过 0.86 dB。差值的 95% 置信区间按场景整群 bootstrap 计算，只反映测试窗口的抽样，不包含训练随机性。
- 训练数据量（约 71,000 次更新）：25% 子集（400 个 epoch）24.15 dB、50% 子集（200 个 epoch）24.68 dB、75% 子集（130 个 epoch）24.06 dB，全量 100 个 epoch 为 24.46±1.12 dB。
- 场景划分：划分 A（C1–C5 训练、C6–C10 测试，180 个 epoch，70,020 次更新）为 7.64 dB，划分 B（反向，220 个 epoch，70,620 次更新）为 7.84 dB；十个留出场景在随机窗口划分下的等权均值为 24.27 dB。参照点由 `diag_e4_shift.py` 和 `diag_e4_eval.py` 产生：折模型在自身训练窗口上为 24.66 和 25.98 dB；留出窗口上，输入三通道均值和训练目标通道均值两个不训练的基线为 9.79/9.56 dB（A）和 10.69/9.79 dB（B）；留出输入的强度对齐到训练场景后为 7.32 和 7.89 dB（整体对齐）、7.04 和 7.74 dB（逐窗口对齐）。
- 数据质量统计覆盖全部 4:1 窗口与归档图块：逐波段均值、标准差、取 255 比例、波段间相关、纹理尺度（lag-1 与频谱重心）以及 FFT 循环互相关的模态间位移。对齐可判定的窗口（峰值相关不低于 0.2）中位移不超过 1 像素的比例为 76.6%（归档图块 76.1%）；不可判定的窗口占 16.9%（归档图块 12.2%）。

两套数据的 PSNR 差值不解释为数据质量的差值。稿内列出可核对的差别：纹理尺度相近；本数据集 RGB 目标取 255 的比例和通道间相关更高，可能使 PSNR 偏高；归档数据在 100 个 epoch 时的更新次数多 4.7%。
