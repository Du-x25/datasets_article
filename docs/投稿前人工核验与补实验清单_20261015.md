# 多波段数据集论文投稿前核验清单

本清单承接 2026 年 10 月 15 日的双语审稿修订。当前结果仍来自十个地点、五折、训练种子 11 和暂定共同支持。正文修订、已有掩膜统计和保存图像的局部展示不等于完成了人工验收或新增实验。

**执行约束：本轮不启动训练。** 以下任务没有因写入清单而自动执行；重训、追加推理或重新采集应在相应前置核验完成后另行安排。优先完成数据身份和独立质量证据，再决定哪些模型结果需要更新。

## 必须完成的人工核验

### H1 确认实际采集配置与八位处理链

- 建议负责人：采集负责人及数据整理者。
- 输入：原始采集记录、设备和滤光片资料、源图清单、RGB 选帧记录、拼接配置及处理代码。
- 操作：逐项核对相机型号、滤光片型号和名义通带、B1 至 B5 文件映射、曝光和增益、采集顺序及可恢复的时间间隔；追踪源文件位深至八位 TIFF 的归一化、截断、RGB 调整、插值、接缝和裁切。
- 交付物：带证据位置和确认人的采集参数表；逐处理步骤的输入、输出和配置版本；未知字段清单。
- 完成标准：每个写入论文的采集事实可追溯；不能恢复的字段标为未知，不用后测值冒充历史采集记录。历史波段设计推理不能替代实际通道身份确认。
- 对训练的影响：仅补文档不需要训练；若发现波段错标、输入强度或几何发生实质变更，先进行影响评估。

### H2 核清同平台旧资源与本资源的关系

- 建议负责人：原采集参与者、旧论文作者与本稿数据整理者。
- 输入：旧论文及其原图、图块清单；当前 1,281 文件档案、840 选中源帧、60 幅成图及地点记录。
- 操作：先用文件哈希识别完全重复，再对重新编码、裁切或拼接产物核查内容对应；由知情作者确认旧宏场景与 C1 至 C10 的物理地点映射。未知关系单列，不能计为新增。
- 交付物：旧资源到当前资源的映射表，包含旧标识、当前标识、关系类型、证据、确认状态；汇总完全重复、同地不同采集、新增、重新处理和未知数量；说明新增元数据、质量记录、协议或公开可用性。
- 完成标准：论文可以定量说明重叠与增量；确认素材复用与公开发布权利。不要求所有图像均为新采集。
- 对训练的影响：来源披露通常不需要训练；若发现训练与测试跨地点身份错误，先修正身份和划分，再评估受影响运行。

### H3 完成六模态全景质量及隐私巡检

- 建议负责人：人工审核者；复核争议项时增加第二审核者。
- 输入：当前六模态成图、几何和隐私合并掩膜、局部对照图、源图及拟发布的预览和标注产物。
- 操作：覆盖十个地点，标记局部错配、运动不一致、接缝或重复纹理、无效边界，以及人脸和车牌等需要处理的区域；没有发现问题也要记录已检查，待查与通过分开。
- 交付物：逐地点巡检记录、带原因的质量和隐私区域、处理前后版本绑定、争议及缺失记录。
- 完成标准：全部拟发布对象有明确审核状态；现有 C10 遮蔽和自动动态范围掩膜不能替代全量检查。无需把全部像素做语义标注。
- 对训练的影响：先记录改动范围。仅评价掩膜变化可重评分；训练输入、训练损失支持、窗口池或划分变化需评估重训，不能自动沿用旧结果。

### H4 确认发布范围与许可

- 建议负责人：数据权利持有人及论文作者。
- 操作：确认源图、成图、代码、模型权重和第三方实现分别可公开的范围及许可；确认拟采用的数据许可、必要的数据引用和作者信息。
- 交付物：发布范围及权利确认记录、数据和代码许可文件、第三方依赖及引用清单。
- 完成标准：拟发布包中的每类对象均有明确授权或可适用许可；未完成的隐私处理对象不进入公开包。

## 必须补齐的验证和复现

### V1 独立几何验证

- 前置条件：固定待验证的源图身份、变换、裁切和输出版本；排除用于变换拟合、调参和开发试点的检查点。
- 操作：在十个地点按空间位置和难度分层抽取可辨认静态点，覆盖相关模态及接缝、边缘和低纹理等困难区域。执行先前协议中的每视野 3 至 5 点、约 25% 第二观察者独立复核，或在观察正式验证结果前记录并说明新的抽样范围和精度目标。不能将 12 视野开发试点改名为正式验证。
- 交付物：原生坐标或缺失原因、盲法任务、独立观察记录、变换身份；逐地点和模态对的有效数、中位数、P95、误差分布、覆盖图及观察者差异。
- 完成标准：能判断实际残差与声明用途是否相容；通过完整变换报告输出及原生网格单位，不用统一除以 3.2 冒充全部局部比例。共享检查点和同视野观测的依赖性必须保留。
- 训练要求：无需新训练。若验证后修改了图像或变换，再进入 V2。

### V2 定版支持与现有结果一致性复算

- 前置条件：H1、H2、H3 及 V1 发现的问题已经分类；明确哪些改变只影响文档、评价掩膜、训练输入或划分。
- 操作：固定数据、掩膜、窗口、指标支持和协议版本，重新汇总逐地点覆盖。若仅评价支持改变，使用保存预测复算可支持的指标；感知指标使用重新确定的完整有效矩形。若原预测未保存或不覆盖所需范围，先列出缺项，再另行安排推理。
- 交付物：版本差异表、受影响运行清单、最终支持统计、主表与图表复算记录。
- 完成标准：每项数字绑定同一发布版本；变化前后的结果不能混用。数据或训练条件发生实质变化时，仅列出需重训的具体运行及理由，不自动启动。

### V3 从审稿包独立复现

- 前置条件：H4 通过，且 V2 的版本固定。
- 操作：在干净环境或由未参与脚本开发的操作者，从审稿可访问包下载、校验并读取六模态；核对地点划分和掩膜；用保存预测复算至少一个完整地点，并尽可能复算全部主表。检查点推理属于另行明确安排的步骤，不默认重训。
- 交付物：审稿链接、文件清单与校验值、数据字段说明、固定代码版本、环境和命令、预期输出与容差、独立执行记录和失败项处置。
- 完成标准：外部操作者不依赖作者机器上的绝对路径即可完成最小流程；数据和代码有可访问版本。首投是否要求公开 DOI 按目标期刊规定核实，不能用“拟上传”替代审稿可访问性。

## 仅在保留更强结论时需要的实验

| 拟保留的结论 | 需要补充的证据 | 当前处理 |
|---|---|---|
| 五波段稳定优于其他输入，或模型排序具有稳定性 | 固定数据与支持后的核心比较重复训练、训练和验证过程及预算诊断；分析种子差异 | 仅保留当前单种子结果中的指标取舍，不宣称稳定优势；不启动额外种子 |
| 11.78 dB 代表一般跨地点泛化落差 | 预先记录窗口规则，在保存模型上覆盖全部相关折和地点的可比诊断 | 移出摘要和贡献主线，保留有限首折诊断 |
| 波段数提升材料可分性、反射率或物理光谱定量能力 | 相应光谱响应、辐射定标、材料标签和实测验证 | 维持名义通带、未定标八位 DN 的用途边界 |
| 人工质量筛选能改善训练效果 | 固定质量池与对照、控制窗口和预算后的质量池实验 | EX-4 不属于当前稿件的必做项 |

三种训练种子、所有模型重新训练、追求 SOTA、新网络、完整语义分割和新外场采集，均不作为本稿数据集定位下的无条件任务。

## 完成顺序与核验记录

1. H1 与 H2 可并行；H3 在身份稳定的图像上开展，H4 同步处理。
2. 固定几何版本后开展 V1；若返工，保留版本和验证集合的隔离记录。
3. 根据实际变更执行 V2；仅列出而不自动启动需要训练的工作。
4. 打包后执行 V3，再核对中英文主张和最终表图。

每项记录负责人、开始及完成日期、输入版本、输出路径、核验人和未解决项。证据文件存在、审核完成和满足投稿用途是不同状态，不以文件名中的 formal、final 或 freeze 作为完成证明。
