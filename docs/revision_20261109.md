# 中文稿实验整合：2026-11-09

核心论点：M-SWIR-RGB 的贡献是可追溯的多波段配对观测及地点隔离的评价条件；实验用于说明波段收益、划分敏感性和目标地点监督的适用边界，不提出新的生成算法。

## 证据选择

| 问题 | 纳入证据 | 解释边界 |
|---|---|---|
| 多波段是否普遍获益 | D 正式基准，3 模型 × 15 输入 × 5 折，225 次；每折在验证地点选择单波段和三波段 | 单训练种子；模型与地点相关的描述性差异，不能用测试最高分选择主结果 |
| 划分是否改变评价 | pix2pix 的 15 输入 × 3 随机划分，45 次；450 对共同区域重评分 | 先在地点内平均，再对十地点等权；训练覆盖及样本组成同时变化，不作单因素因果解释 |
| 目标地点配对样本有什么作用 | separated_calibration.csv；B134 仿射映射的跨地点和地点内拟合；二次映射另列 | 同一地点的评价像素完全一致；目标配对监督不是未知地点泛化，也不是传感器辐射定标 |
| 校准的空间适用范围 | disjoint_calibration.csv；十地点、两个对向半区、三种采样方式 | 同一半区比较共享评价像素；与整地点校准实验的掩膜不同，禁止跨表直接作差 |
| 预测局部表现 | C1/C5/C8 的验证集选波段图板，中心最近有效窗口 | 固定位置独立于预测质量；不重新增强图像，不推断总体排名 |

A/B/C 的旧数据复现、随机切片和批量大小诊断以及 E/F 的重叠切片适配，不进入主文方法排名。不同校准预算排除的区域不同，不用其汇总数声称纯粹的样本量收益。旧版 30 次训练、末步模型、仅 B1 错位、11.78 dB 首折窗口诊断不再作为新版结论。

## 术语与主张

- 地点隔离：每折 6 个训练地点、2 个验证地点、2 个测试地点；十地点各测试一次。
- 单波段 / 三波段：S_i 为 B_i 复制三通道；T_ijk 为依次排列的三个不同波段，网络通道数一致。
- 验证集选择：先选每次训练的最佳验证检查点，再在每折每模型的单/三波段候选中按验证 PSNR 选输入；测试值不参与选择。
- 配对颜色校准：用目标地点的 SWIR–RGB 样本拟合像素映射；不等于辐射定标或无监督色彩迁移。
- 统计单位：主结果为十个地点；450 条重评分记录不是 450 个独立样本。本文不报告显著性或多种子稳定性结论。
- 人工独立几何验收、全量质量/隐私验收、公开许可及 DOI 均仍待完成。

## 图形契约（绘图前确定）

采用现有 Python/Matplotlib 工作流。输出 PDF、SVG 和 PNG；不输出 TIFF。画布宽 183 mm，正文按版心缩放；使用可嵌入字体、直接标注、统一颜色，数值轴保留有意义单位。无显著性星号或虚构误差条。

1. 波段收益：模型均值连接图 + 十地点增益热图，展示收益随模型和地点变化。
2. 划分敏感性：逐地点配对 PSNR + 测试像素被训练窗口覆盖比例；不同量使用独立面板。
3. 配对校准：整地点三方法与半区三条件分别绘图，分开坐标和支持说明，展示每个地点及均值。
4. 定性图：三个固定地点 × RGB/验证选择单波段/验证选择三波段；复用已导出图板的嵌入图像，保持显示范围，记录源图和 ROI。
5. 验证轨迹（附录）：固定 T124 的三模型五折记录，用于说明最佳验证检查点选择，不声称收敛或公平算力。
