## 3. 五模型规格与必要适配

以下结构来源已核查；本节标为“建议”的补充数值属于待冻结实现细节。

| 模型 | 拟采用实现规格 | 保留的训练目标 |
|---|---|---|
| U-Net回归 | 建议与标准pix2pix使用同一U-Net-256生成器：8级下采样、基础64通道、BatchNorm；训练时相同dropout设置，评价关闭dropout | L1像素回归；不增加对抗项 |
| 标准pix2pix | 官方U-Net-256及70×70 PatchGAN；输入C通道，输出3通道，条件判别器输入C+3通道 | 标准BCE对抗损失＋100×L1 |
| TFD-GAN | 论文表4.1–4.4：64通道头、4级下采样至1024通道、12个CBAM残差块、4级PixelShuffle及跨层拼接；局部3×3判别器、全局5×5判别器 | LSGAN＋10×特征匹配＋10×VGG感知＋5×低频颜色损失 |
| Restormer | dim=48，blocks=[4,6,6,8]，refinement=4，heads=[1,2,4,8]；实际C通道输入、3通道输出；移除末端输入直接相加 | L1回归，保留内部Transformer结构 |

U-Net与pix2pix在分别调参后仍是各自的基准；不能把两者全部差异严格归因于是否使用GAN，除非另设参数完全相同的对照。

### 3.1 TFD细节

- 依据学位论文正文明确的数值，建议输出卷积使用3×3。表4.3泛称“大核卷积”，本次采用正文给出的具体尺寸，并在实现说明中记录该选择。
- 局部与全局判别器均为5层卷积，步长2、2、2、1、1；建议通道64、128、256、512、1。全局输入采用2×2平均池化、步长2。这些未被论文逐项明确的实现值，作为本次补充参数公开。
- 判别器保持条件形式，输入为SWIR与真实／生成RGB的拼接；两分支按论文公式合并。
- 特征匹配采用逐元素Charbonnier：sqrt(d²+ε²)，ε=10^-6，对各层有效元素取均值后求和；真实分支特征停止梯度。不能将ε误写成直接加10^-6而不平方。
- VGG-19使用relu1_1至relu5_1，层权重1/32、1/16、1/8、1/4、1；输入按对应预训练权重要求归一化。
- 颜色损失为21×21、σ=3的高斯低通后L1；建议用反射边界，避免零填充产生额外暗边。
- 论文中的结果数值不作为v3结果或验收目标。TFD依据：`D:/USTC/Gen/article_chen/陈启栋-学位论文.pdf`，正文46–54页（PDF60–68页）。

### 3.2 Turbo必须显式处理的事项

1. **首层初始化。** 建议将原RGB首层三组权重求和后除以新通道数C，再复制到C个输入通道，偏置保留。对重复单波段输入，该初始化保持原三通道重复输入的首层响应；本轮代数检查误差低于6×10^-15。其目的为确定、对称的初始化，不代表已经学会波段映射。
2. **训练参数。** 标准路线先冻结基础权重，再显式开放LoRA、规定的跳连、UNet入口和改造后的VAE入口；新入口必须加入优化器。LoRA默认秩UNet=8、VAE=4。
3. **保存参数。** 新VAE入口权重和输入通道配置必须随检查点保存。官方仅筛选LoRA／skip的VAE保存逻辑需要扩展。
4. **空文本条件。** 固定空字符串，不从GT生成描述；关闭caption相似度损失。CLIP视觉辅助判别器保留，预训练资源单独披露。
5. **增强。** 视觉辅助判别器的DiffAugment默认为开启，包含color、translation、cutout；本方案建议显式关闭，以遵守已确认的增强范围。
6. **随机性。** 官方名为deterministic的路径仍调用latent_dist.sample()。建议训练保留受种子控制的采样；验证／测试使用潜变量后验均值，固定为所有条件共同的推理适配，不按样本挑随机输出。
7. **更新计数（已确认4B）。** 保留官方分步更新：先进行重建／感知更新，再进行对抗更新，判别器也保留官方更新顺序。分别记录外循环、生成器／判别器实际更新次数和样本使用量；不能用相同外循环数冒充相同优化更新预算。
8. **从头训练对照。** 已接受额外增加VAE、UNet及生成器跳连随机初始化、全参数训练的分支。不能冻结随机骨干而只训练LoRA。文本编码器及感知／判别特征网络若仍使用预训练权重，单独列明；结果名称为“生成网络随机初始化”，不写成整个系统零预训练。
9. **输入通道覆盖。** 实施验收对B1–B5逐一扰动，检查每波段确实进入网络和梯度路径；不能因可运行而把五波段挤成未训练的三通道接口。

## 4. 本轮建议冻结的统一参数

### P01：质量掩膜进入训练的方式

本项已由用户选择1A确认。

**先按局部掩膜选出完全有效的256×256训练窗口，再让五模型在相同窗口上计算各自原始损失。** 质量筛选仍标在局部区域，不整视野剔除；保留该视野其他有效窗口，同时报告因窗口支持范围额外损失的有效面积。

理由：TFD的InstanceNorm、Turbo的全局注意力／视觉特征等会把局部信息传播到其他位置，简单在最后一层损失乘掩膜，不能保证已排除不一致监督。对训练图涂黑同样会改变判别与感知特征。

- 未筛选训练池：仅要求无效边界与隐私掩膜全部通过，保留研究对象中的动态／配准问题。
- 质量筛选池：另外要求动态／局部配准失败掩膜全部通过。“全部通过”的训练窗口规则已确认；具体掩膜边界由标注预览与复核确定。
- 随机减量池：从未筛选池随机选择，与筛选池在各地点的窗口数严格相同，并尽量匹配原始视野贡献与去重空间面积。
- 固定每条件的训练更新数与抽样规则，记录窗口数、重复计数像素量、去重覆盖面积、原始视野贡献及匹配偏差。不将“裁块数相同”单独解释成空间覆盖完全相同。
- 随机减量采用固定种子生成候选子集，只按来源和覆盖信息选择，不按模型结果选择。具体覆盖匹配容差应在掩膜完成后的抽样可行性表中一次冻结。
- 如果希望使用跨越掩膜的部分有效裁块，作为后续单独的掩膜训练方案讨论，不默默混入主对照并改变不同模型的监督范围。

### P02：数据加载与完整场景推理

- 统一清单读取实际C通道SWIR张量及3通道RGB，通道顺序按B1至B5升序；重复单波段是显式实验条件。
- 样本主键由数据版本、地点、坐标、窗口尺寸组成；fold和实验条件通过清单引用，不复制为新的独立观测。
- 训练先按地点等概率采样，再在地点内按冻结的空间分层规则采样。小地点不通过复制文件伪造额外数据量。
- 尾端起点为图像尺寸减256，去重后补入规则网格。默认不缩放图像，不丢失右端和下端覆盖。
- 推理每窗256、步长128，合并使用可分离权重：一维w(t)=sin²[π(t+0.5)/256]，二维权重为乘积，再按实际累计权重归一化。权重严格为正，避免边界除零。
- 先在浮点域合并，再进行统一[0,1]截断与评价；另记录截断前越界比例。浮点预测与用于展示的8位图分开保存。
- 接缝来源要记录RGB及五波段各自的视野标签和低频／细节融合权重。由于低频与细节分开融合，不把单一标签当成精确的全像素来源。

### P03：训练预算与调参

**已确认2B：先做专门预算校准，再冻结正式预算与验证频率。已确认3A：12组学习率／预热候选、五种子，损失权重固定。** 下表中具体更新次数、batch和验证间隔保留为校准参考，不作为已接受的正式训练数值。

| 项目 | 建议值 |
|---|---|
| 预算校准参考 | 可检查100,000／200,000／400,000次生成器／回归器更新附近的验证表现；正式上限由校准确定 |
| 有效batch | 4；显存需要时梯度累积，按模型固定物理batch并记录，不能把梯度累积当成等价BatchNorm统计 |
| 验证频率参考 | 校准阶段可从每2,000次更新及最后一次验证开始；正式频率随后冻结，在两个完整验证地点评价 |
| 检查点 | 保存最佳与最后状态；PSNR完全相同选择较早检查点 |
| 停止规则 | 正式对照不按条件分别提前停止；按固定预算完成 |
| 调参机会 | 每模型每折12组候选，全部使用5种子，只看验证地点 |
| 候选构成 | 4个学习率×3个warmup长度（0、1000、5000更新）；损失权重按上述固定 |
| 学习率轨迹 | warmup结束后余弦衰减至初始学习率的1%；这是统一实验设置，不称为原作者完整训练日程 |
| 精度 | 建议BF16混合精度；损失汇总与评价保留FP32或更高精度；记录实际硬件与精度 |

学习率候选建议：

- U-Net、pix2pix、TFD：5×10^-5、1×10^-4、2×10^-4、4×10^-4。
- Restormer：5×10^-5、1×10^-4、2×10^-4、3×10^-4。
- 标准Turbo：2×10^-6、5×10^-6、1×10^-5、2×10^-5。
- Turbo生成网络随机初始化：5×10^-5、1×10^-4、2×10^-4、3×10^-4，作为单独初始化分支获得同样调参机会。
- U-Net建议Adam(0.9,0.999)，pix2pix／TFD为Adam(0.5,0.999)，weight decay=0；Restormer为AdamW(0.9,0.999)、weight decay=10^-4；Turbo为AdamW(0.9,0.999)、weight decay=10^-2。

**专门预算校准（2B）：**在展开完整矩阵和查看测试结果前，使用五波段训练／验证数据检查各模型学习曲线、稳定性及不同预算下的验证表现。100,000／200,000／400,000为待细化的观察档位，不预先保证任何一档足够。校准后冻结更新次数、验证频率、学习率日程及有效／物理batch；相同模型同折的后续E2/E4/E5条件沿用同一比较预算。预算校准的训练启动仍属于后续实施阶段。

训练期间数值失败保留失败日志，排查实现或数值原因后使用同一种子重跑，不能换种子补出更好结果。来源、代码、配置完全相同的调参获选运行可以复用为E1，测试必须等选择冻结后再运行。

### P04：评价指标

| 维度 | 建议固定口径 |
|---|---|
| RGB PSNR | [0,1]浮点RGB，先在每地点共同有效像素及三通道上计算MSE，再转换为PSNR；不是平均裁块PSNR |
| RGB误差 | MAE和RMSE，主表给[0,1]尺度，便于阅读时附×255的灰度级误差 |
| 颜色 | 采用明确声明的sRGB编码解释、D65白点、2°观察者转换至Lab；计算CIEDE2000，报告均值、中位数、P95 |
| SSIM | RGB各通道后平均；data_range=1；高斯σ=1.5、11×11支持、总体协方差；仅统计完整支持位于有效区域的中心点 |
| 感知 | LPIPS-Alex v0.1，仅在预先冻结的完全有效矩形上计算；训练用LPIPS-VGG与评价用Alex分开说明 |
| 完整场景 | 所有指标基于同一份合并浮点预测，逐指标记录支持面积 |

颜色差异是针对发布RGB图像的编码颜色计算，不解释为物体实测色差。v3没有嵌入ICC，sRGB属于本实验明确采用的计算约定。

**LPIPS采用已确认6B：**在查看模型结果前，选定完全有效的固定矩形，五模型及相关实验条件共用。在合并后的预测与参考图上提取同一矩形，调用标准LPIPS，不自定义按特征层掩膜重加权的主指标。单独报告矩形数量、尺寸、地点和去重覆盖面积；不能将矩形子集的LPIPS称为全场景所有有效像素的感知误差。无法提供合适矩形的小区域记为不适用，其他像素／颜色指标仍可报告。验收检查与官方实现一致、矩形完全有效、且模型结果未参与矩形选择。

总体报告10个地点的结果和五种子波动；按相同地点／种子报告差值和正负方向。默认不把50个地点×种子结果当50个独立样本做显著性检验。若需要置信区间，另明确交叉验证训练集合重叠带来的解释范围。

### P05：区域与失败案例

- 区域数量由主要内容覆盖和可辨识性决定，先生成候选清单，再一次冻结；不为了某类别凑数。
- 像素误差在多边形与质量掩膜交集内计算；SSIM遵循完整窗口支持规则，LPIPS仅在预先选定的完全有效矩形上计算。细标线等小区域可能只有像素／颜色指标。
- 每类别报告覆盖地点数、区域数和去重有效面积。类别跨地点等权，而非大面积地点主导。
- 失败案例建议按种子11、共同有效候选窗口中的ΔE00排序，逐地点保留高误差案例；重叠窗口先去重，列出选择规则和所有模型同位置结果。主文选代表案例，完整清单随补充材料提供。

## 5. E1–E5完整执行矩阵与解释口径

### E1：五波段多模型基准（已确认）

五模型×五折×五种子＝125次训练。输入为五波段，训练池采用质量筛选后数据，评价整场景重建、颜色、结构、感知、地点差异、成本及失败模式。标准Turbo保留基础预训练，资源透明列出。

### E2：地点多样性与数据量（已确认，补充抽样规则）

**地点多样性：**每折从六个训练地点穷举全部15个两地点组合、15个四地点组合，加六地点组。三种地点数的总训练裁块数相同，各组内地点平衡。

建议由该折训练池容量确定统一N：N为不超过2×最小地点容量的最大12倍数。这样N能同时被2、4、6整除，所有组合都无需重复文件来补足独特样本量。相同地点在不同组合中使用同一种子的嵌套排序取样，记录来源与实际去重覆盖。

**数据量：**六个训练地点固定，10%、25%、50%、100%嵌套抽样；各地点分别按比例取样并采用地点平衡的训练采样概率。建议在规则空间分区内分层产生固定随机序列，报告实际去重覆盖面积，不把10%裁块直接称为10%独立场景信息。

**复用规则：**数据量100%组复用E1。地点多样性中的六地点组按统一N取样，是该分析自己的对照；若其索引、预算等恰与另一运行完全一致，才按运行签名复用。

新增运行计数：31个地点多样性条件＋3个数据量条件，每条件125次，共4,250次；不含调参。

### E3：外部迁移（已确认，补充控制）

来源分别报告：RASMD为主SWIR来源；EPFL RGB-NIR为补充；更新版OMSIV为第三候选，须样本核查后冻结。分别开展外部样本量匹配与外部全量实验，不混成一个来源不明的大池。

每来源、模型、折、种子包含：

1. 外部配对数据训练后直接测本数据留出地点；单通道维度一致。源模型检查点只用外部验证数据选择。
2. 本数据训练地点从头训练；单波段与五波段基线按实际条件复用E4/E1。
3. 外部预训练后用本数据训练地点微调，验证地点只作选择；新测试地点不微调。
4. 五波段迁移时将已经训练的单通道入口扩展为五通道，再进行目标训练地点微调。生成器首层按W/5复制，条件判别器只扩展SWIR部分，RGB部分保留；入口变化和优化器重置显式记录。
5. 不把未训练的随机输入适配器接在源模型后称为五波段zero-shot。单通道zero-shot可以逐一测试B1–B5；与本数据训练模型比较时使用E4已经冻结的验证最佳单波段，并同时展示各波段结果。
6. 标准Turbo与生成网络随机初始化分支分开报告，禁止混用两种初始化的名称。

建议主迁移预算为源阶段U＋目标阶段U，其中U为该模型该折冻结预算；同时增加本数据单独训练2U的对照，区分额外训练更新与外部数据作用。微调学习率搜索为基准获选学习率的0.1、0.3、1倍，五种子选择规则不变。

外部数据拆分以原始图像／序列／地点分组，不能将相邻帧或同图裁块散到源训练与源验证两边。优先遵循官方划分，再从源训练集合按组产生验证集合。外部样本量匹配除裁块数外同时报告原图数、序列数和独特空间覆盖。

本次核对官方页面：EPFL为477图像对、9类、1024×768；更新OMSIV为500组配准数据，RGB-NIR是四通道，必须仅提取其NIR通道作为红外输入。RASMD本身不是本数据的五窄波段同谱替代物。

本地发现的NIR-RGB_final_v1是另一套1,622组、三通道NRGB数据，现有说明未确定通道物理定义；本次未把它追加为上述外部单通道来源。epdata/mldata的目录名也不构成其为EPFL的证据。

### E4：波段信息与输入维度（已确认）

每模型每折每种子训练的独特输入条件为：

- 5种单波段；10种三波段（包含B124）；完整五波段；5种四波段逐一移除。
- 根据五种子平均验证结果确定最佳单波段与最佳三波段，不另进行“最佳组合”重复训练。
- 最佳单波段重复至3通道、5通道，再训练两组，区分新增光谱信息与输入维度变化。
- 不增加B124重复至5通道。

### E5：数据质量与处理影响（框架及六项处理替换已确认）

**A. 独立检查点与顺序采集。** RGB–各波段及全部波段对的检查使用同一物理位置。报告可用点数、缺失原因、地点覆盖、误差中位数、RMSE、P95及完整分布；第二人原始标注的一致性在协商前计算。顺序采集不一致依据可见运动、轮廓与照明变化记录，不从滤轮额定速度推算实测间隔。

- `prepare_annotation_results.py`：生成逐原因质量掩膜、显式混合类别及属性掩膜、完全有效 256×256 窗口、等量随机候选及 LPIPS 候选。区域需当前版本 B 同意后才按已确认区域处理；待复核区域另存。生成材料标为候选，不自动冻结。
- `quality_matching.py`：只用视野来源和去重面积选择等量随机子集，输出实际匹配偏差；匹配容差待真实掩膜产生后确定。
- `data.py`：只从 v3 场景清单读取，核对哈希、真实波段数、256 窗口及范围；实现显式单波段重复、同步水平翻转、地点等概率采样和抽样状态恢复。
- `v3core.py`、`evaluate_scene.py`：正权重浮点拼接；逐像素 PSNR／MAE／RMSE；sRGB、D65、2° 下的 ΔE00；完整 11×11 有效支持的 SSIM；官方 LPIPS-Alex 0.1 固定有效矩形评价。
- `aggregate.py`：地点内五种子平均，再地点等权；按相同地点与种子配对。类别缺失不能填零；不把裁块作为独立统计样本。
- `models.py`、`turbo.py`、`losses.py`：五模型、条件判别器、TFD 损失、Turbo 标准／生成网络随机初始化分支。首层、LoRA、跳连、权重快照及空文本条件有明确接口。
- `experiments.py`、`training_steps.py`：7,125 项 E1/E2/E4 配置、实际优化器更新与样本使用计数、模型／优化器／调度器／随机状态恢复，以及 Turbo 分步更新接口。
- `geometry_controls.py`：在原生 B1 坐标定义的受控平移、四方向均衡分配、训练后单通道入口向多波段扩展。
- `e5_fullscene.py`、`render_scene.py`：六项已确认 E5 单因素全场景变体；固定 v3 坐标、已有增益及隐私处理；保存逐图哈希、变换、掩膜与共同交集。
- `source_weights.py`：所有候选窗口在 RGB/B1–B5 中的真实低频／细节融合来源贡献及硬标签图。低频和细节贡献分别保存，隐私填充的来源贡献为零。

## 实现约定与验收边界

- U-Net／pix2pix 保留 Tanh 输出；Turbo 保留官方输出范围约束。评价器在浮点拼接后统一截断，不做额外逐窗量化。Restormer 去掉输入直接相加。
- TFD 输出卷积为正文中的 3×3；两分支 LSGAN 使用论文 1/2 系数。特征匹配取每分支四个中间激活，逐层平均后求和，Charbonnier ε=10^-6；VGG19 使用 relu1_1 至 relu5_1，颜色低通为 21×21、σ=3、反射边界。
- Turbo 验证／测试使用后验均值；训练要求显式传入带种子的随机生成器。标准分支开放新入口、LoRA 和规定跳连；随机初始化分支开放整个生成网络。标准适配检查点保存入口基础权重和输入配置；完整续训使用通用训练状态接口。
- Turbo 保留重建 G、对抗 G、真实 D、生成 D 的顺序，实际为每外循环两次 G、两次 D。G 阶段隔离 D 参数梯度；D 调度器按官方每外循环推进一次。视觉判别器关闭 DiffAugment；固定 CLIP 特征资源单独记录。
- LPIPS 矩形分数逐个保留，报告矩形等权平均及去重覆盖。当前接口支持边长至少 64 的矩形；无法设置适当矩形的区域记不适用。实际矩形尚待人工区域冻结。
- 现阶段的前向、反向和优化器检查使用构造输入，证明程序接口与数值路径可运行；人工配准精度、质量筛选效果、正式模型性能和最终预算由后续真实数据产生。
- 受控平移的坐标接口已测试；各幅度的全场景派生产物在真实共同掩膜和实际残差分布明确后生成。E3 外部数据审查与正式运行结果另行产生。

运行 `python -m pytest -q` 检查本目录单元及导出／评价端到端用例。模型实测分别运行 `check_models.py`、`check_turbo.py`、`check_turbo_scratch.py`、`check_losses.py`、`check_turbo_step.py`。`audit_e5.py` 复核 195 张完整场景产物。

# 五、人工标注工作台使用手册

# v3光谱标注工作台 · 使用手册

本工具用于原图检查点、内容／质量多边形、独立B复核和另存协商结果。已接入140视野的840个模态来源。它不修改原图，不训练模型，不自动把示例圈心当作人工坐标。

## 一、启动与试标

1. 在本文件所在目录双击 **启动A初标.vbs**。稍等，浏览器打开A工作台。
2. 首次使用填匿名编号，如A01。建议先用一个有清楚建筑角点或标线的视野试操作，熟悉保存和导出，再全量进行。
3. 主机上的第二人双击 **启动B复核.vbs**。A尚未生成任务时，B端显示等待。B端没有切换为A的操作入口。
4. 当前主机已配置可用Python和Pillow。运行不需要GPU或训练环境。页面只连接本机，不向外网发送图像。

浏览器关闭后服务可继续在本机运行；再次双击同角色入口会重新打开已有服务，不重复建立同角色工作台。若未自动打开，A地址为`http://127.0.0.1:18765`，B地址为`http://127.0.0.1:18766`。关闭页面前须确认顶部显示“已保存”。

**存储位置：**同目录`标注结果`存放正式记录；`历史记录`保留替换前的版本，`图像缓存`是由v3 TIFF生成的展示PNG。复制或备份整个`标注结果`目录即可保留记录。不要把测试坐标混入正式结果。

## 二、A检查点操作

1. 左侧选地点和视野，右上模式保持“检查点定位”。右侧位置按钮默认01–10；确有需要可增加位置。
2. 为当前位置填写唯一物理描述，选择难度。重复窗格需写清层数／列数／具体框角。
3. 顶部依次选RGB、B1–B5，**在每幅原图独立点击同一物理位置**。准星和右侧坐标表立即更新，修改会自动保存；也可以点顶部“保存”。
4. 滚轮缩放，右键拖动或按住空格拖动；“平移”按钮可将左键改为拖动。“适应窗口”看全图，“1:1”显示原像素大小。显示缩放不会改变已保存的原图坐标。
5. 看不清的模态选择缺失原因，不猜坐标；“其他”需填具体说明。“清除当前模态坐标”同时清空该模态状态，需要重新落点或说明缺失。
6. 如果一个预留位置无法找到可用静态结构，点击“此位置均不可辨认”，填写原因，记录六模态缺失。不是要求每个视野无条件凑满10个有效点。
7. 所有位置都处理后，填写必要的视野说明，点“检查并完成本视野”。漏模态、未说明的空值、缺少描述／难度／人员编号会阻止完成，并显示原因；草稿仍可保存。

快捷键：1–6切换模态，N/P切换位置，Ctrl+Z撤销本次会话内最近的点位或区域修改。编辑文字时这些快捷键不拦截正常输入。重新载入后若需要恢复旧记录，由管理员查看历史版本；不建议直接覆盖当前文件。

坐标采用原图像素中心、从0开始的(x,y)：RGB 2048×2048，SWIR 640×512。点击可能记录两位小数，这只是显示精度，不等于定位准确度。圈定的物理位置不能是连续边缘上的任意一点、反射亮斑或阴影边界。

## 三、生成并完成B独立复核

1. A完成一个地点的全部视野后，点左下 **生成本地点复核任务**。程序在该地点可用物理位置中按难度分层抽取约20%，保存固定抽样清单。
2. 抽样采用每地点总量四舍五入（非空地点至少1点），按难度占比最大余数法分配。小层可能因样本很少分不到位置；实际层配额、比例及固定种子都保存在复核任务记录。不可反复抽样挑选容易的点。
3. 抽样后，该地点A原始点记录锁定。不要把全量A结果目录交给B。
4. B打开自己的入口并刷新，填不同的匿名编号。B只获得抽中位置、物理描述和RGB 256×256粗搜索范围；**服务端不会把A精确坐标发送给B页面**。A的RGB缺失时无粗框，B依据文字描述独立寻找。
5. B按相同方法在六模态独立定位、填自己的难度和缺失原因。“检查并完成”后B原记录锁定，防止看到分歧后回改独立测量。
6. 不同地点可以流水推进：A继续下一地点，B复核已交接的地点。B不必等全部140视野完成。

约1400个物理位置对应A最多约8400个模态坐标；20%复核大约280个物理位置、最多约1680个模态坐标。实际数量由可辨认性决定。

## 四、第二人用另一台电脑

1. A生成一个或多个地点的B任务后，点 **打包异机B任务**，下载ZIP。包内包含所需原图、只含粗提示的任务、B版工具；没有A的精确坐标或A原始记录。
2. 将这个ZIP交给B。B解压到普通文件夹后双击`启动B复核.vbs`。该包固定为B角色；即使给启动脚本传A参数，也不会提供A入口。
3. 异机需有Python 3.10及以上和Pillow。工具自动查找随包`python/python.exe`、Codex自带Python、`D:/anaconda3/python.exe`及系统Python。若没有可用环境，启动器会提示管理员准备，**不会静默联网安装**。异机环境未在本机测试范围内。
4. B完成后点“导出结果”，将结果ZIP交回A。

## 五、A/B分歧怎样处理

B完成某视野后，A可把模式切换为 **A/B协商副本**。页面分别显示A蓝色、B橙色及协商副本黄色准星。未被抽中的点显示“B未抽样”。

协商副本初始复制A位置，状态为草稿，不代表两人已经达成一致。回看物理描述和各原图，填写协商理由，确需修改时重新落点，再完成并保存。A/B独立原记录保持不变，第三份记录写入`标注结果/协商`。程序不自动按分歧大小删除点，也不要求配准残差必须小于某个任意阈值。

应先导出原始A/B记录供一致性统计，再解释／处理分歧。协商记录不能代替原始一致性结果。

## 六、内容与质量区域操作

1. 切换 **内容与质量区域**，页面载入该地点v3成图。首次载入某模态会生成无损PNG缓存，稍等即可；数据较大，不是图像卡死。

3. 点 **新建多边形**，依次单击边界顶点；至少3点后点击 **结束绘制**。撤销可退回顶点，取消绘制丢弃未完成边界。多边形自交、越界或面积不足会被拒绝保存。
4. 用模态按钮查看同一成图坐标的各波段。记录备注，将边界状态设置为草图、待复核或已核查确认；不是画完就默认有效。
5. 在列表选择已有区域，可修改类别、属性、备注和状态。当前版本修改边界的方法为删除该多边形后重画；删除可在当前会话用撤销恢复。

20%是检查点复核比例，不自动等于所有区域／质量掩膜只审查20%。明确疑点需逐项解决。当前工具保存多边形和质量原因，**尚不自动生成最终栅格掩膜、三组训练池或冻结LPIPS矩形**；这些由后续统计与数据处理步骤完成。
