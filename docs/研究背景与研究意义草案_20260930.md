## 1. 研究问题（一句话钉死）

**深度跨光谱生成方法的训练与评价需要成对的 RGB–SWIR 数据；但现有配对资源在光谱（单宽带无波段可分性）、几何（双相机残余视差混入真值对）、协议（图块级随机划分导致空间信息泄漏）三个环节存在系统性缺口。本研究构建并文档化一个在上述三个环节都可审计的地面级 RGB–五波段 SWIR 配对数据集，使跨光谱生成模型的能力与失效模式第一次可以被可靠地测量。**

这不是模型论文（正文已明确"不以提出新模型为目标"），研究问题不是"怎么生成图像"，而是"什么样的数据才能让生成模型被可靠地训练和评价"。

## 3. 想证明的逻辑链（章节骨架）

每一章回答一个问题，串起来正好是背景中承诺的三个缺口逐一被响应：

1. **背景与概要**：为什么需要这个数据？——应用价值（SWIR 能看见可见光看不见的）→ 方法瓶颈（有监督跨光谱生成依赖配对数据）→ 三缺口 → 三个设计决策。
2. **方法·采集平台**：缺口 2 的硬件响应——共孔径为什么从原理上消除视差，残余失配来自哪里。
3. **方法·光谱波段定义**：缺口 1 的响应——五波段怎么选的、为什么是这五个；同时诚实交代两点限制（名义通带、未辐射定标）。
4. **方法·地点身份/拼接坐标/辐射策略**：数据真实性——每一幅图从哪些原图、经什么变换来；哪些解释是不允许的。
5. **方法·独立检查点与标注不确定性**：缺口 2 的验证侧——残余失配由不参与拟合的人工观察独立量化，且量化标注本身的噪声。
6. **方法·内容/质量区域与隐私**：复用适用性——哪些区域可分层评价、哪些必须被排除、为什么。
7. **数据记录**：供给事实——60 幅 TIFF、140 视野、1281 原图、SHA-256 绑定。
8. **技术验证·协议**：缺口 3 的响应——五折五种子、三池对照、共同冻结测试支持、指标支持定义。
9. **使用说明与局限性**：边界——十个地点不是地理代表性抽样、质量筛选可能不提升指标、阴性结果保留。

逻辑主张一句话：**数据集的每个设计决策都对应背景中指出的一个缺口，每章为该决策提供一项可审计的证据；缺任何一章，背景承诺就有落空的环节。**

## 4. 研究意义（四层）

1. **对跨光谱生成研究（直接）**：提供公开可得的极少数地面级、场景级多波段 SWIR 配对资源，使三类此前无法严格进行的研究成为可能——(a) 波段消融（哪些 SWIR 波段对着色/生成真正有用，E1/E2）；(b) 配准误差对生成质量的敏感性（受控错位，E4/E5）；(c) 数据质量筛选的成本–收益对照（三池，E2/HAV-C）。单宽带数据集在原理上无法支持 (a)，未独立量化配准的数据无法支持 (b)，泄漏划分的数据无法支持 (c)。
2. **对数据发布与复现实践（方法论）**：把独立检查点、盲法双人标注、质量多边形、地点隔离划分、预注册数据池作为数据集发布的组成部分，回应机器学习可复现性与泄漏问题\cite{kapoor2023,pineau2021,cawley2010,roberts2017}；为"小规模、深文档"路线（相对"大规模、浅文档"）提供范例——10 个地点不是大样本，但每个环节可审计、可复算。
3. **对下游应用（间接）**：SWIR→RGB 着色服务于无 SWIR 显示经验的人员/系统的影像解读；材质分层（植被/枯草/路面/水体）支撑地面应用与遥感验证；恶劣条件下的多模态感知\cite{song2024,bijelic2020fog}。
4. **对数据生态（长期）**：探测器技术进展使 SWIR 成像成本下降、应用面扩大\cite{rogalski2003,yu2024}，可信配对数据成为应用落地的瓶颈环节；FAIR、可引用、带溯源的公开资源降低后续研究门槛\cite{wilkinson2016,sansone2019}。

```latex
\section{背景与概要}
短波红外（SWIR）成像在两类任务上提供可见光难以获得的信息。其一，植被、枯草、裸土、水体、路面等典型地物在SWIR波段的反射率差异与可见光的颜色差异并不一致，一些在RGB中难以区分的材质在SWIR中可分\cite{song2024}。其二，SWIR辐射受雾、烟尘等气溶胶的散射衰减弱于可见光，在低照度与恶劣天气下能保持成像能力\cite{narasimhan2002,bijelic2020fog}。随着InGaAs及新兴探测器技术的进展，SWIR成像正从专用遥感走向地面与车载应用\cite{rogalski2003,yu2024}。

上述能力的深度学习利用主要沿跨光谱生成路线：以SWIR输入重建可见光外观（着色），或以可见光合成SWIR波段，服务于SWIR影像的可视化解读与跨模态任务\cite{levin2004colorization,zhang2016colorful,chen2025,chen2026threeband}。与可见光--红外分割、检测和匹配任务一样，这类有监督方法依赖像素级对齐的配对资源\cite{isola2017,ha2017,hwang2015,jia2021,razakarivony2016}；配对数据的对齐质量与光谱覆盖直接决定模型能力上限与评价结论的可信度。

然而，公开可得的RGB--SWIR配对资源（表~\ref{tab:related-zh}）在三个环节存在系统性缺口。光谱维度：RASMD的SWIR为单个宽带通道（1000--1700\,nm）\cite{jin2026}，波段间的材质光谱差异信息在其数据中不存在；DeepSWIR由卫星多传感器粗分辨率波段合成\cite{rout2019}；EPFL资源覆盖近红外而非SWIR\cite{brown2011}。几何维度：两台独立相机加事后配准的方案（如RASMD的SIFT单应与RANSAC\cite{jin2026}、AVIID的分开航拍\cite{aviid2023}）把残余视差留在``真值对''内部，且多数发布未独立测量该失配。协议维度：同平台早期发布的4000对图块采用随机4:1划分\cite{chen2026threeband,chen2026thesis}，同一场景的图块同时进入训练与测试，空间信息泄漏使跨地点泛化能力不可知\cite{kapoor2023}；以帧为单位的划分中，相邻帧的高度相关性使跨场景外推同样难以估计\cite{roberts2017}。此外，多数资源的溯源、质量与标注可靠性未被系统记录（表~\ref{tab:related-zh}中的``n.r.''条目），复用者难以判断适用范围\cite{gebru2021,wilkinson2016}。

M-SWIR-RGB针对上述缺口各有一个设计决策。光谱上，五个SWIR窄带（B1--B5）依据大气与探测器响应的能量模型在采集前确定，使``哪些波段、多少波段对着色与生成有用''成为可以在同一数据上回答的问题；通带为滤光片名义规格，装配系统的光谱响应未实测，是本数据的明确限制。几何上，采集采用共孔径二向色分光平台，两个传感器经同一入射光瞳观测场景，双相机方案的视差在光路层面被消除，残余失配只来自两支路像元间距与后光路差异，并由不参与任何变换拟合的独立人工检查点量化。协议上，十个不同物理地点的十个场景拼接图以地点隔离的五折、五种子方式划分，测试支持在模型评价前冻结，辅以盲法双人标注、内容与质量多边形和版本化溯源，避免图块级随机划分的泄漏模式\cite{cawley2010,roberts2017}。

本数据的预期用途是跨光谱生成与多模态研究的训练与严格评价：波段消融与波段数--性能权衡、配准误差对生成质量的敏感性（受控错位）、数据质量筛选的成本--收益对照，以及SWIR→RGB着色与RGB→SWIR合成的方法比较。本数据描述稿的贡献是原始观察、地点身份、处理来源、独立人工证据与可复用评价协议，而不是新模型；十个互异地点不构成地理代表性抽样，独立人工验证统计与正式基准结果在协议冻结后另行报告\cite{kapoor2023,pineau2021}。同平台既有工作与本数据的原图重叠及新增内容需在投稿前完成披露。
```
